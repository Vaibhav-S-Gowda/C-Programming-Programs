## 🛠 How to Compile and Run

To compile any C program, you need a C compiler such as **GCC** installed.

### Compile a program
```bash
gcc filename.c -o outputname
```

### Run the executable
```bash
./outputname
```

### Example
```
gcc linked_list.c -o linked_list
./linked_list
```
